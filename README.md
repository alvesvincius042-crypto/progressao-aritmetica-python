# Progressão Aritmética (PA) em Python

## Sobre o projeto

Programa desenvolvido em Python para calcular e exibir os termos de uma Progressão Aritmética (PA).

O usuário informa o primeiro termo e a razão da progressão. Inicialmente, o programa apresenta 10 termos e permite solicitar a exibição de quantos termos adicionais desejar.

## Funcionalidades

- Recebe o primeiro termo da PA.
- Recebe a razão da progressão.
- Exibe os 10 primeiros termos.
- Permite adicionar novos termos conforme a solicitação do usuário.
- Finaliza a execução quando o usuário informa 0.

## Conceitos de Python utilizados

- Variáveis e tipos numéricos.
- Entrada de dados (`input`).
- Estruturas de repetição (`for` e `while`).
- Função `range()`.
- Operações aritméticas.
- Controle de contagem e iteração.

## Como executar

1. Tenha o Python instalado.
2. Baixe ou clone este repositório.
3. Execute o arquivo Python pelo terminal ou por uma IDE, como PyCharm.

## Exemplo de utilização

**Entrada:**
- Primeiro termo: 2
- Razão da PA: 3

**Saída inicial:**
```text

5
8
11
14
17
20
23

29
```

O programa perguntará quantos termos adicionais o usuário deseja visualizar.
